# Code of Conduct

This project adopts the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith, and keep
discussions about the work. Harassment, personal attacks, and
discriminatory behavior are not tolerated anywhere in the project's
spaces (issues, PRs, discussions, chat).

Report unacceptable behavior privately to the maintainer via the email
on the GitHub profile. Reports are handled confidentially.
